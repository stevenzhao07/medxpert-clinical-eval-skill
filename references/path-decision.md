# 临床评价路径判定 · 三路径决策树

> 输入：产品分类 + 产品特性 → 输出：临床路径（A/B/C三选一）

---

## 三条路径总览

| 路径 | 说明 | 成本 | 周期 |
|------|------|------|------|
| **A · 免临床** | 有目录/规则支持，不需要新做临床 | 最低 | 最短 |
| **B · 同品种比对** | 用已上市产品数据+差异论证，免新试验 | 中 | 中等 |
| **C · 临床试验** | 自己做临床实验，产生新数据 | 最高 | 最长 |

---

## 一、中国NMPA路径判定

```
是否列入《免于临床评价医疗器械目录》（2025版，1047项）？
   ├─ 是，且所有条件完全匹配 → 【路径A：免临床】
   │     依据：目录第XXX项
   │
   ├─ 是，但适用范围有差异 → 差异小可论证免临床，差异大走比对
   │
   └─ 否 → 能否找到同品种做比对？
       ├─ 能找到 + 数据可比 + 差异论证充分 → 【路径B：同品种比对】
       └─ 找不到/差异太大 → 【路径C：临床试验】
```

**关键注意点**：
- 现行免临床目录是2025版（19号通告），旧2023版已失效
- 同品种比对必须证明：适用范围/技术特征/生物学特性/制造工艺 四方面实质等同

---

## 二、美国FDA路径判定

```
走510(k)路径？
   ├─ 有Predicate Device + 无重大差异 → 【路径B：实质等同比对】
   │     （用Predicate数据 + 自身bench test，通常免新临床）
   │
   ├─ 无Predicate / 重大差异 → 【路径C：临床试验支持】
   │
   └─ PMA路径 → 【路径C：临床试验（通常必需）】
```

**关键注意点**：
- 美国没有中国式的"免临床目录"，"临床豁免"体现在510(k)用Predicate比对
- PMA高风险器械：临床试验数据基本必需

---

## 三、欧盟MDR路径判定

```
Class I 自我声明？
   ├─ 是 → 仍需CER，但可用文献+等价器械数据 → 【路径B：CER】
   │
   └─ Class IIa及以上 → 证据充分吗？
       ├─ 文献 + 等价器械数据充分 → 【路径B：CER】
       └─ 证据不足 → 【路径C：临床调查】
```

**关键注意点**：
- MDR下所有类别都需要临床评价（即使Class I）
- 等价性论证是CER核心：解剖/生理/技术特性都要等价

## 输出格式

```markdown
### 临床路径判定结论

| 项 | 内容 |
|---|------|
| 产品 | [产品名称] |
| 目标市场 | [中国/美国/欧盟] |
| **临床路径** | [A免临床 / B同品种比对 / C临床试验] |
| 判定依据 | [免临床目录第XXX项 / Predicate XXX / MDR Annex XIV] |
| 数据缺口 | [还缺什么临床数据] |
| 周期影响 | [临床阶段预估 X-Y 个月] |
| 置信度 | [确定 / 高概率 / 待确认] |
```

> ⚠️ 临床判定是注册里最容易翻车的地方。拿不准就标"待确认"，建议和临床评价顾问复核。
