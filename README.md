## 这是什么？

临床评价是医疗器械注册里**成本最高、周期最长、最容易翻车**的环节。

这个Skill帮你：
- 判定临床路径：免临床 / 同品种比对 / 必须做临床试验
- 搭CER报告框架：临床评价报告应该包含哪些部分
- 列出数据缺口：还缺什么临床数据
